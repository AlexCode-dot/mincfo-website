# Demo Placeholder Snapshot

This folder contains a frozen snapshot of the hero demo placeholder implementation.

## Snapshot files
- `Hero.demo-placeholder-snapshot.tsx`
- `Hero.demo-placeholder-snapshot.module.scss`

## Purpose
Use these files to restore the exact previous demo placeholder visuals (including masks, glow, play button styling, and shadow treatment) after experimenting with new demo videos.

## Restore approach
1. Compare `Hero.tsx` against `Hero.demo-placeholder-snapshot.tsx`.
2. Compare `Hero.module.scss` against `Hero.demo-placeholder-snapshot.module.scss`.
3. Copy back the snapshot sections (or replace entire files if desired).
